# Contributing to I'm In

Thanks for taking the time to contribute.

This project is open source because it is meant to serve a community, not be owned by one person or group. That said, it is not a free-for-all. There are some clear rules and expectations to keep things useful, safe, and aligned.

---

## How to contribute

1. Fork the repo
2. Create a feature branch
3. Make your changes
4. Open a pull request with a clear explanation

Keep PRs focused. Small, clear improvements are much easier to review and merge.

---

## What we're looking for

- Improvements to usability and clarity
- Bug fixes
- Performance improvements
- Accessibility improvements
- Clear, simple features that align with the core purpose

---

## What we are not looking for

- Features that add complexity without clear value
- Anything that compromises privacy or safety
- Features that centralise control of activities or communities
- "Platform power" features (ranking users, boosting posts, etc.)

---

## Core principles (non-negotiable)

- Privacy comes first
- Safety comes first
- Hosts must be the actual host of the activity
- No one owns the community
- Keep things simple

If a contribution conflicts with any of the above, it will not be merged.

---

## Code guidelines

- Keep things simple and readable
- Avoid unnecessary abstractions
- Follow existing patterns in the codebase
- Do not introduce heavy dependencies without discussion

---

## Before submitting a PR

Ask yourself:

- Does this make it easier for someone to host or join an activity?
- Does this keep things safe and simple?
- Would someone new understand this without explanation?
- If this changes user-facing behavior, did I update `CHANGELOG.md`?

If not, rethink it.

---

## Decision making

All pull requests are reviewed by the maintainers.

Not all contributions will be merged. That's not personal, it's about keeping the product coherent and aligned with its purpose.

---

## Discussions

If you're unsure about something, open an issue first and outline your idea before building it.

---

## Final note

This is a community tool, but it still needs direction.

Contributions are welcome. Direction is curated.
